# Logistics Operations & Fleet Performance Analysis Dashboard

## Project Overview

This project presents a comprehensive logistics analytics solution developed using Power BI, Power Query, DAX, SQL Server, and Excel.

The dashboard provides operational insights into fleet utilization, driver performance, route profitability, maintenance activities, fuel expenditure, customer revenue, and safety performance.

---

## Business Problem

Logistics companies generate large volumes of operational data across deliveries, drivers, vehicles, maintenance activities, and customer shipments.

This project transforms raw operational data into actionable business insights that support better decision-making and operational efficiency.

---

## Key Insights

- Revenue performance remained stable across operational periods.
- Revenue generation was concentrated among high-value customer accounts.
- Certain truck categories handled significantly more operational trips.
- Route profitability varied considerably across destinations.
- Maintenance spending did not consistently reduce fleet downtime.
- Safety incidents were concentrated within specific operational segments.
